# Bites — AI-Powered Food Delivery App

Bites is a full-stack food delivery web app built with **TanStack Start** (React + file-based routing + SSR). It lets users browse restaurants and dishes, get AI-driven recommendations, chat with an AI food assistant, track nutrition, and place and track orders — all with prices in Indian Rupees (₹).

## Features

- **Restaurant & dish discovery** — browse by category, cuisine, rating, delivery time, and veg/non-veg filters
- **AI recommendations** — personalized dish/restaurant suggestions based on order history and preferences (`AiRecommendations`, `AdvancedRecs`)
- **AI chat assistant ("Bites AI")** — a chat widget that helps with meal picks, nutrition questions, and combo suggestions, including food image analysis
- **Combo suggestions** — smart combo/add-on recommendations while browsing a dish
- **Cart & checkout** — address management, multiple payment methods, and coupon/discount support
- **Order tracking** — live order-status timeline (placed → preparing → out for delivery → delivered)
- **Order history** — view past orders and reorder in one tap
- **Nutrition tracking** — log meals, track daily calories/water intake, and view charts (via Recharts), with export to Excel/Word
- **Light/dark theme** support

## Tech Stack

- **Framework:** [TanStack Start](https://tanstack.com/start) (React 19, file-based routing via TanStack Router, SSR via Nitro)
- **Styling:** Tailwind CSS v4 + [shadcn/ui](https://ui.shadcn.com) components (Radix UI primitives)
- **Data/state:** TanStack Query, React Context (cart, theme, addresses)
- **AI:** [Vercel AI SDK](https://sdk.vercel.ai) (`ai`, `@ai-sdk/react`, `@ai-sdk/openai-compatible`) calling an AI gateway from a server route
- **Charts:** Recharts
- **Forms:** React Hook Form + Zod
- **File export:** `docx`, `xlsx`, `file-saver`
- **Tooling:** Vite, TypeScript, ESLint, Prettier, Bun

## Getting Started

### Prerequisites

- [Bun](https://bun.sh) (this project uses `bun.lock` and `bunfig.toml`) — Node.js + npm/pnpm/yarn also work if preferred

### Installation

```bash
bun install
```

### Environment Variables

The AI chat assistant requires an API key for the AI gateway:

```bash
LOVABLE_API_KEY=your_key_here
```

### Development

```bash
bun run dev
```

### Build & Preview

```bash
bun run build
bun run preview
```

### Linting & Formatting

```bash
bun run lint
bun run format
```
